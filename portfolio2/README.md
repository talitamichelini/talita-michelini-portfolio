# Portfólio — Talita Michelini

Site estático em um único arquivo: `index.html` (HTML, CSS e JavaScript, com as imagens embutidas). Não precisa de backend nem de instalação.

## Páginas
Início, Sobre mim, Projetos, Ferramentas e Contato. A navegação usa o endereço (`#inicio`, `#sobre`, `#projetos`, `#ferramentas`, `#contato`).

## O que editar
Tudo fica no começo do bloco `<script>` do `index.html`:

- `CONFIG`: seus links (GitHub, LinkedIn, e-mail e WhatsApp). Campo vazio fica desativado na página.
- `PROJECTS`: título, descrição, tecnologias e imagens de cada card.
- `TOOLS`: as categorias da página Ferramentas (a faixa em movimento usa a mesma lista).

## Publicar
Qualquer hospedagem de site estático serve (Vercel, GitHub Pages, Netlify). Basta o `index.html` na raiz do repositório.
